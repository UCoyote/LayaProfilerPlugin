# Laya Profiler

Laya Profiler 是一个用于 LayaAir Web 游戏的 Chrome DevTools 扩展。打开 DevTools 后会新增 `Laya Profiler` 面板，用于查看运行时状态、节点层级、游戏配置、资源快照、GPU 内存归因、页面控制台日志和监控指标。

- 插件版本：`0.1.24`
- 作者：UCoyote
- 邮箱：501202461@qq.com

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择解压的插件目录：`LayaProfilerPlugin`。
5. 打开一个 LayaAir Web 游戏页面，按 `F12` 打开 DevTools。
6. 在 DevTools 顶部选择 `Laya Profiler` 面板。

## 顶部监控

- 自动检测当前页面中的 Laya 运行时。
- 顶部显示 `FPS`、`FrameTime`、`HeapUsed`、`GPUMemory`、`DrawCall`、`Node`。
- 支持全局搜索节点、资源和日志。
- 支持暂停采样和手动刷新。
- 面板宽度不足时保持横向布局，并通过横向滚动查看内容。

## 节点层级

- 递归读取 `Laya.stage` 显示树。
- 展示节点类型、路径、子节点数量、销毁状态等信息。
- 支持节点过滤、展开全部、折叠全部、刷新层级。
- 支持暂停或恢复游戏计时器，并可修改 `Laya.timer.scale`。
- 支持选中节点后在舞台上显示红色框选标记，框选位置会计算父节点变换后的舞台坐标。
- 支持快捷修改节点常用属性：名称、激活、可见、位置、尺寸、锚点、缩放、倾斜、旋转、透明度、鼠标触摸、`zOrder`。
- 支持将当前选中节点输出到 Chrome Console，输出的是真实节点对象，可在控制台展开对象并修改字段。

## 游戏配置

- 自动检测全局 `window.config` 对象。
- 遍历 `config` 对象中字段名以 `Tbs` 结尾的成员，作为游戏配置表展示。
- 读取配置表对象的 `data` 字段，并展示所有配置数据。
- 配置表列表支持搜索。
- 配置数据支持搜索字段、路径和值。
- 配置数据使用虚拟列表渲染，减少数据量过大时的卡顿。
- 支持展开和折叠对象、数组结构。
- 支持动态修改 `number`、`string`、`boolean`、JSON 对象和数组数据。
- 数组字段支持新增条目和删除条目。
- 修改数组内部字段时，修改列表会记录父数组的原始值和修改后的完整数组值。
- 保留初始配置快照，并自动记录运行时修改。
- 提供「修改列表」查看当前改动，列表中展示原始值和当前值。
- 支持将当前所有修改保存为模板，可自定义模板名称。
- 支持选择模板后预览修改内容，并一键应用模板数据。
- 提供「重载Worker配置」按钮；当 `window.RELOAD_WORKER_CONFIG` 是函数时，会直接调用 `window.RELOAD_WORKER_CONFIG()` 并刷新配置快照。

## 开发面板

- 支持切换 `Laya.Stat` 面板。
- 支持触发资源回收：调用 `Laya.Resource.destroyUnusedResources()`，并在可用时调用 `window.gc()`。
- 支持暂停 `Laya.timer`。
- 支持恢复 `Laya.timer`。
- 命令执行结果会输出到开发面板中。

## 资源管理

- 支持创建当前资源快照。
- 快照列表显示资源数量和 GPU 内存总量。
- 支持选择快照查看资源清单。
- 支持删除快照。
- 支持选择两个快照进行差异比较。
- 选中一个快照后，会列出除自身外的其他快照，可快速发起比较。
- 比较模式显示资源变化类型，包括新增、移除和变更。
- 资源表展示预览、对象名、来源、GPU 内存、资源类型、尺寸、引用计数。
- GPU 内存、资源类型、尺寸、引用计数和变化类型支持排序。
- 图片资源支持缩略图和悬停大图预览。
- 非图片资源会显示不可预览提示。

## GPU 内存

- 汇总显示 GPU 总量、已归因、未归因和对象数。
- 按资源类型进行 GPU 内存归因分组。
- 分组项支持点击展开。
- 展开后展示资源路径、资源名称、尺寸和占用的 GPU 内存大小。
- 优先读取资源对象和内部纹理对象上的显存字段。
- 缺失显存字段时，会按纹理尺寸和格式估算 GPU 内存。

## 控制台

- 默认停靠在底部区域。
- 包装页面 `console.log`、`console.warn`、`console.error`，采集页面运行时日志。
- 支持按 `All`、`Log`、`Warn`、`Error` 分类过滤。
- 日志内容和时间戳颜色跟随日志类别。
- 支持搜索当前控制台日志。
- 支持清除当前控制台日志。
- `warn` 和 `error` 日志支持调用堆栈。
- 有堆栈信息的日志前显示展开箭头，默认折叠，点击箭头后展开。
- 堆栈调用深度已扩展，便于查看更完整的调用链。
- 点击堆栈中的源码行号，会跳转到 Chrome DevTools Sources 面板对应源码行号位置。

## 监控信息

- 展示当前运行时关键数据：`FPS`、`FrameTime`、`HeapUsed`、`GPUMemory`、`DrawCall`、`Node`、`Sprite`、`Triangle`。
- 维护最近一段时间的监控历史。
- 使用折线图展示帧率、帧耗时、堆内存、GPU 内存和 DrawCall 趋势。

## 分页和停靠

- 支持将主要分页拖拽到底部区域停靠。
- 控制台默认停靠到底部。
- 底部区域支持上下拖拽改变高度。
- 停靠后的分页仍可拖回主区域。
- 窄宽度下顶部信息和监控卡片保持横向布局，通过横向滚动查看。

## 兼容说明

不同 LayaAir 版本和项目封装方式差异较大，资源缓存、GPU 显存和配置对象会使用兼容式探测。能从引擎对象读取到的字段会直接显示；缺失字段会使用近似估算，适合定位趋势和大对象，不等同于浏览器底层精确显存统计。
